### Sponsored Lightning talk - Peeriot: Myrmic: An Open Rust Runtime for Distributed Edge Applications
Myrmic is an open-source runtime for distributed edge applications. It provides execution, messaging, state handling, and placement for application logic running across heterogeneous edge and embedded devices, without requiring a central cloud service in the control path.

This lightning talk introduces two core aspects of the system. First, Myrmic provides a complete runtime stack for building and coordinating distributed applications across the edge. Second, its dual-engine architecture separates portable, sandboxed application logic from device-specific native Rust code, allowing applications to span gateways and microcontrollers without hiding hardware capabilities behind a lowest-common-denominator abstraction.

In five minutes, attendees will get a compact view of the overall stack, the dual-engine design, the capabilities it enables, and the trade-offs it introduces. Myrmic is open source, and the implementation will be available after the session.

### Making GPUs Feel Native in Rust
GPUs power AI, graphics, scientific computing, and an increasing share of modern software. Many projects focus on making GPU programming in Rust possible. This talk asks a different question: how do we make GPU programming feel native to Rust?

Christian Legnitto, founder and CEO of VectorWare, explores what it would take to make GPUs feel natural extension of the Rust language and ecosystem. The talk covers the challenges and design tradeoffs involved in bringing Rust's ownership model, type system, and abstractions to heterogeneous systems. It also looks at compiler architecture, intermediate representations (IRs), runtimes, and the fundamental differences between CPU and GPU execution.

Attendees will leave with a framework for thinking about how GPU and CPU software interact, an understanding of today's tradeoffs, and a vision for how Rust can make heterogeneous programming feel like ordinary systems programming.
